Huzaifa Mohamed Personal Website - Static HTML

Structure:
- huzaifa/index.html              Main personal page
- huzaifa/projects/index.html     Projects page
- huzaifa/assets/css/style.css    Design styles
- huzaifa/assets/js/main.js       Language switch + mobile menu + animations
- huzaifa/assets/img/             Portrait, OG image, favicon

How to use:
1. Upload the entire "huzaifa" folder to your website public root.
2. The page will open at: success-step.com/huzaifa/
3. The projects page will open at: success-step.com/huzaifa/projects/

For Next.js/Vercel:
- Put the "huzaifa" folder inside the /public folder.
- Then deploy. The route will be /huzaifa/ automatically.

Notes:
- Arabic is default.
- English works from the AR/EN switcher.
- Contact buttons are active: phone, email, WhatsApp, LinkedIn.
