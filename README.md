# Khatwat Najah Awwwards-style Website

Next.js + React + Tailwind CSS + GSAP + ScrollTrigger + Framer Motion.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

- The JPEG logo was converted to `public/images/logo-transparent.png`.
- Replace Unsplash placeholder images with your real company service/project images.
- Contact form is visual only. Connect it to Formspree, Web3Forms, or your backend before production.
